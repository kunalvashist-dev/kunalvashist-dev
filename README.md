## 🚀 What I'm Building

### 🤖 Xenora AI

**Xenora AI** is my personal AI assistant project, focused on combining artificial intelligence with practical system interaction and automation.

The project explores:

* 🧠 Memory and contextual interaction
* 🤖 Local AI and LLM integration
* ⚙️ Task automation
* 🔌 Tool and API integration
* 🖥️ System interaction
* 🔊 Offline voice capabilities

**Status:** `ACTIVE DEVELOPMENT`

**Status:** `ALWAYS BUILDING`
